# 培養データ トリミング＆エクスポート

培養ロガーCSVをオフラインで結合し、A～D各ジャーの有効区間を独立して調整して、ネイティブExcelグラフ付き `.xlsx` を出力するStreamlitアプリです。

## 最初に読むところ

**ファイルを1個ずつダウンロードする必要はありません。フォルダ一式をZIPでダウンロード・展開して使用します。**

利用方法は、受け取ったものによって異なります。

### 社内配布された完成版を使う場合（推奨）

完成版フォルダには `cultivation-trimmer.exe` が含まれています。

1. 配布されたZIPを右クリックし、**「すべて展開」**します。
2. 展開したフォルダ内の **`run.bat` をダブルクリック**します。
3. ブラウザが自動で開いたら使用できます。

Pythonのインストールやインターネット接続は不要です。フォルダ内のファイルは削除・移動せず、一式のまま使用してください。

### Gitリポジトリのソース版を使う場合

GitHub等からソースを取得した場合は、`cultivation-trimmer.exe` がまだ含まれていません。

1. リポジトリ全体をZIPでダウンロードして展開します。
2. Python 3.11以上をインストールします。
3. 初回だけ **`setup_and_run.bat` をダブルクリック**します。
4. 2回目以降は **`run.bat` をダブルクリック**します。

`setup_and_run.bat` の初回実行時のみ、依存パッケージ取得のためインターネット接続が必要です。手動で起動する場合は次を実行します。

```bat
python -m pip install -r requirements.txt
run.bat
```

## 操作手順

1. サイドバーで26列のロガーCSVを複数選択します。Row 3を表示用ヘッダー、Row 2を型情報として読み込みますが、実データは列位置で解釈します。
2. 重複INDEXに対する「後」の順序を、ファイル名昇順または選択順から選びます。結合後も欠落INDEXは補間しません。
3. 各ジャータブでグラフを確認し、範囲スライダーまたはINDEX直接入力で開始・終了を調整します。
4. 自動検出は、指定点数だけ続くポンプ立ち上がりと温度低下を使います。開始が検出できない場合は全区間、終了のみ検出できない場合は末尾へフォールバックします。
5. エクスポートタブで対象ジャーと結合元データの有無を選び、Excelをダウンロードします。各Jarシートには全6項目の編集可能なExcel折れ線グラフが入ります。

## 自動検出パラメータ

- `START_THRESHOLD`（既定5）: ポンプ立ち上がり判定値
- `PRE_ZERO`（既定2）: 立ち上がり直前に必要なゼロ点数
- `RISE_PERSIST`（既定3）: しきい値以上が続く必要点数。単発100スパイクを除外します。
- `END_TEMP_THRESHOLD`（既定10℃）: 終了判定温度
- `COOL_PERSIST`（既定3）: 終了温度未満が続く必要点数

欠損・未接続センサー値はエラーにせず、数値またはNaNとして表示・出力します。

## サンプルCSVでの確認手順

1. 288行、INDEX 35276～35563のサンプルCSVを読み込み、結合後行数・期間・重複解消件数・欠落INDEX数を確認します。
2. 全ジャー自動検出を実行します。AはINDEX 35406付近、CはINDEX 35407付近から始まり、単発100を無視し、終了は末尾になることを確認します。
3. Bは検出不成立の警告とともに全区間へフォールバックすることを確認します。
4. A/Cだけを選択してExcelを出力し、`概要`、`JarA`、`JarC` のみがあり、Jarシート右側に6個の編集可能なグラフがあることを確認します。

## 管理者向け: 完成版の作成と配布

ビルド用PCで `build.bat` を実行します。生成された `dist\cultivation-trimmer` フォルダをZIP化し、そのZIPだけを利用者へ配布してください。利用者は展開後に `run.bat` をダブルクリックするだけで起動できます。
